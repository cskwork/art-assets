# Kid-Friendly Playful Image Prompts

This document outlines the prompt structure for generating cohesive, high-quality, 2D vector-style art assets for lower elementary education.

## Base Style Keywords
Use these keywords to ensure consistency across all generated images:
> **cartoon style**, **wide aspect ratio**, **high quality 2d vector art style**, **flat design**, **bright colors**, **soft lighting**

## Design Principles
- **Open Space**: Always include "open space for content" or "open space in center" to ensure the background works for educational slides using text.
- **Vibe**: "Friendly", "Warm", "Inviting", "Cute", "Not scary".
- **Target Audience**: Lower elementary school students.

## Prompt Template
```
[Subject/Topic Description], cartoon style, [Specific Details], [Atmosphere/Vibe], open space for content, wide aspect ratio, high quality 2d vector art style, flat design
```
