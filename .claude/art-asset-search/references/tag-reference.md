# Tag Reference

Art Asset Search 스킬용 전체 태그 목록 및 분류.

## 교육 수준 (Education Level)

| 태그 | 설명 | 예시 에셋 |
|------|------|----------|
| `elementary` | 초등학교 | 귀여운 UI 아이콘, 기초 산수, 세기 블록 |
| `middle-school` | 중학교 | 좌표평면, 분수, 일차함수 |
| `high-school` | 고등학교 | 포물선, 적분, 삼각함수, 플라톤 다면체 |
| `advanced` | 심화/대학 | 복소 평면, 벡터장, 리만 곡면 |
