# 피타고라스 정리 - 3D 큐브 증명

## 메타 정보

| 항목 | 값 |
|------|-----|
| **주제** | 피타고라스 정리 (a² + b² = c²) |
| **과목** | 수학 |
| **학년** | 중학교 2학년 |
| **생성일** | 2026-01-27 |
| **기술 스택** | Three.js r160, ES Modules, OrbitControls |

## 학습 목표

1. 피타고라스 정리의 기하학적 의미 이해
2. 3D 시각화를 통한 넓이 관계 직관적 파악
3. 다양한 직각삼각형에서 정리 검증

## 7씬 구조

| 씬 | 내용 | 인터랙션 |
|----|------|----------|
| **Hook** | 세 정사각형 3D 등장 | 카메라 회전 |
| **Anchor** | 정사각형 넓이 복습 | 격자 시각화 |

| **Core** | 슬라이더로 변 조절 | a, b 변 조절 → c² 자동 계산 |
| **Visualize** | 공식 도출 | 공식 플로팅 텍스트 |
| **Quiz** | 6-8-? 빗변 계산 | 4지선다 |
| **Wrap** | 요약 및 자유탐색 | 축하 파티클 |

## 핵심 기능

### 3D 인터랙션
- **OrbitControls**: 마우스/터치로 360° 회전
- **실시간 업데이트**: 슬라이더 조작 시 3D 모델 즉시 반영
- **카메라 애니메이션**: 씬 전환 시 부드러운 이동

### 교육 요소
- **발견 기반 학습**: 직접 조작하여 a² + b² = c² 검증
- **시각적 증명**: 정사각형 넓이로 피타고라스 정리 이해
- **실시간 피드백**: 슬라이더 조작 → 수식 자동 업데이트
