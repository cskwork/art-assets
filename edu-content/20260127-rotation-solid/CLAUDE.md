# 회전체 - 2D에서 3D로

## 메타 정보

| 항목 | 값 |
|------|-----|
| **주제** | 회전체 (원기둥, 원뿔, 구) |
| **과목** | 수학 |
| **학년** | 중학교 3학년 |
| **생성일** | 2026-01-27 |
| **기술 스택** | Three.js r160, ES Modules, OrbitControls |

## 학습 목표

1. 회전체의 정의와 생성 원리 이해
2. 평면도형과 회전체의 관계 파악
3. 각 회전체의 부피 공식 학습

## 도형 매핑

| 2D 도형 | 회전체 | 부피 공식 |
|---------|--------|-----------|
| 직사각형 | 원기둥 | V = πr²h |
| 직각삼각형 | 원뿔 | V = ⅓πr²h |
| 반원 | 구 | V = ⁴⁄₃πr³ |

## 7씬 구조

| 씬 | 내용 | 인터랙션 |
|----|------|----------|
| **Hook** | 2D→3D 변환 애니메이션 | 카메라 회전 |
| **Anchor** | 2D 도형 복습 | 3개 도형 나란히 |
| **Story** | 회전체 탄생 이야기 | 타자 효과 |
| **Core** | 도형 선택 + 회전 슬라이더 | 0°~360° 회전 시각화 |
| **Visualize** | 부피 공식 카드 | 클릭으로 전환 |
| **Quiz** | 직각삼각형 → ? | 4지선다 |
| **Wrap** | 3개 회전체 갤러리 | 파티클 효과 |

## 핵심 기능

### 3D 인터랙션
- **도형 선택 버튼**: 직사각형/직각삼각형/반원 전환
- **회전 슬라이더**: 0°~360° 점진적 회전 시각화
- **thetaLength**: Three.js 파라미터로 부분 회전체 렌더링

### 교육 요소
- **점진적 발견**: 슬라이더로 천천히 회전하며 입체 형성 과정 관찰
- **즉각적 피드백**: 360° 도달 시 완성 메시지
- **비교 학습**: Visualize 씬에서 3개 회전체 비교
