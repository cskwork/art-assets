Verb (동사)

행동, 동작을 나타내요

Noun (명사)

사물, 개념을 나타내요

book, idea, creation

"창조하다"가 아니라 "창조(물)" 자체를 말하고 싶다면?

Verb → Noun Converter

동사에 접미사를 붙여 명사로 변환!

Input (동사)
create
-tion
Output (명사)
creation

규칙 1: -te로 끝나는 동사

-te → -tion

create → creation

educate → education

celebrate → celebration

규칙 2: -de로 끝나는 동사

-de → -sion

decide → decision

explode → explosion

include → inclusion

발견! -tion과 -sion을 붙이면 동사가 명사로 변신해요!
