기호 설명

📅 going to = 이미 계획한 일
⚡ will = 지금 막 결정한 일

🎨 패턴을 시각화해볼까요?

⏰ 결정 시점이 중요해요!

📅 going to

be + going to + 동사원형
  • ✓ 이미 계획한 미래
  • ✓ 준비하거나 결정한 일
  • ✓ 증거가 보이는 미래 예측

"I'm going to visit the library."

→ 이미 계획했어요

⚡ will

will + 동사원형
  • ✓ 지금 막 결정한 미래
  • ✓ 자발적 제안/약속
  • ✓ 예측/추측

"I'll help you!"

→ 지금 결정했어요

🔑 핵심 포인트

going to는 이미 마음먹은 일 (계획 📅)
will은 지금 순간 결정한 일 (번개 ⚡)

🌏 한국어와 비교하면?

한국어

"도서관에 갈 거야" (계획)

"도와줄게!" (즉석 결정)

English

"I'm going to visit" (계획)

"I'll help!" (즉석 결정)

영어는 계획과 즉석 결정을 문법적으로 구분해요!
