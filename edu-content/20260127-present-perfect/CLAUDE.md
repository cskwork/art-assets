# Present Perfect Tense - 현재완료시제

## 콘텐츠 정보
- **주제**: Present Perfect Tense (have/has + past participle)
- **영역**: Grammar
- **대상 학년**: 중학교 1-2학년
- **선수 학습**: 단순 과거 시제, 과거분사 형태
- **후속 학습**: 현재완료 진행형

## 핵심 개념
- 과거에 시작된 경험/상태가 현재까지 연결될 때 사용
- have/has + 과거분사 구조
- 시간 표현: ever, never, already, yet, just, for, since

## 파일 구조
- `index.html` - 메인 HTML 파일
- `style.css` - 스타일시트
- `script.js` - 인터랙션 로직
