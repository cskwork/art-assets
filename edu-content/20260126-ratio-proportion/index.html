비례식의 성질

a : b = c : d
↓
a x d = b x c

예시

떡 400g : 4인분 = 떡 600g : 6인분
400 x 6 = 4 x 600
2400 = 2400 ✓

"외항의 곱 = 내항의 곱" 이것이 비례식의 핵심이에요!
