# 콘텐츠 메타 정보

- 모듈 ID: `20260206-phaser`
- 과목: 수학
- 주제: 피타고라스 정리 (아이소메트릭 3D)
- 학년: 중학교 2학년
- 엔진: Phaser 3.80.1
- 표현 방식: 의사 3D (아이소메트릭 2.5D)

## 학습 목표
1. 직각삼각형에서 세 변의 관계를 아이소메트릭 3D 블록으로 시각적으로 확인한다.
2. `a² + b² = c²`를 넓이(부피) 비교 관점으로 설명할 수 있다.
3. 슬라이더 조작으로 다양한 직각삼각형에서 피타고라스 정리가 성립함을 발견한다.
4. c² 또는 c 값을 계산하여 퀴즈에 적용할 수 있다.

## 선수 개념
- 정사각형 넓이 (한 변 x 한 변)
- 제곱의 의미
- 직각삼각형의 정의

## 후속 개념
- 좌표평면 거리 공식
- 삼각비 (sin, cos, tan)
- 벡터의 크기

## 7씬 구조
1. **Hook**: 3D 블록으로 호기심 유발 - "부피 합이 정말 같을까?"
2. **Anchor**: 정사각형 넓이 복습, 2D에서 3D 블록으로 전환
3. **Story**: 건축가 피타의 경사로 설계 (타자 효과)
4. **Core**: 슬라이더(a, b)로 변 길이 조절, 실시간 아이소메트릭 블록 업데이트
5. **Visualize**: a² + b² = c² 공식 도출, 블록 시각 증명
6. **Quiz**: c² 계산 + c 값 계산 혼합 (5문제 풀)
7. **Wrap**: 핵심 3줄 + 피타고라스 수 확장 질문

## 기술 특징
- **아이소메트릭 투영**: `Iso.toScreen(x, y, z)` 함수로 3D→2D 변환
- **3면 블록 렌더링**: 윗면/왼쪽면/오른쪽면 각각 다른 밝기로 입체감 표현
- **MathModel 분리**: 수식 계산 로직과 렌더링 완전 분리
- **파티클 이펙트**: 아하 모먼트 시 색상 폭발 효과
- **타이핑 효과**: 스토리 씬 텍스트 타자기 애니메이션
- **입력 검증**: 슬라이더 값 범위 제한 (2~12)

## 평가 포인트
- 슬라이더 조작 후 좌변/우변 관계를 정확히 설명하는가
- 3D 블록의 크기 비교로 피타고라스 정리를 직관적으로 이해하는가
- 퀴즈에서 c² 및 c 계산을 정확히 수행하는가
- 공식의 의미를 도형 넓이(3D 블록 부피)로 연결하는가
