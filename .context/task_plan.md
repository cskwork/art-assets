# 작업 계획: 콘텐츠 생성 지연 원인 분석 및 속도 개선 계획

## 목표
콘텐츠 생성이 오래 걸리는 이유를 코드 근거로 파악하고, 즉시 적용 가능한 개선안과 구조 개선안을 단계별 계획으로 제시한다.

## 단계
- [x] 1단계: 계획 및 범위 설정
- [x] 2단계: 관련 코드/로그 탐색 및 병목 후보 도출
- [x] 3단계: 실패 원인(파싱 오류) 경로 분석
- [x] 4단계: 속도 개선 계획 수립(빠른 개선/구조 개선)
- [x] 5단계: 검증 전략 및 사용자 확인 포인트 정리
- [x] 6단계: 리뷰/자동수정 분리 API TDD 구현 및 검증

## 핵심 질문
1. 실제로 시간이 오래 걸리는 구간은 어디인가? (생성/리뷰/자동수정/저장/재시도)
2. "Z.ai 응답 JSON 파싱 실패"는 어떤 응답 형태에서 발생하는가?
3. 어떤 개선이 체감 속도를 가장 크게 올릴 수 있는가? (스트리밍/단계 분리/병렬화/재시도 정책)

## 결정 사항
- 계획 스킬(planning-with-files)에 따라 .context 파일로 작업 메모를 유지한다.
